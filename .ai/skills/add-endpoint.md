# Skill: Add an API Endpoint

Use this skill when adding a new endpoint to an existing app — either a custom action on an existing ViewSet, a new ViewSet, or a standalone `CreateAPIView`.

---

## Prerequisites

- The app exists in `apps/` and is registered in settings
- The model exists (if data is involved)
- The app's URLs are included in `config/api_urls.py`

---

## Pattern A — Custom Action on an Existing ViewSet

Use when adding a non-standard endpoint to an existing resource (e.g., `/api/posts/<id>/publish/`).

**In `apps/<appname>/views.py`:**

```python
from drf_yasg.utils import swagger_auto_schema
from rest_framework import status
from rest_framework.decorators import action
from rest_framework.response import Response


class <ModelName>View(..., GenericViewSet):
    # ... existing code ...

    @swagger_auto_schema(
        method="POST",
        request_body=<InputSerializer>,
        responses={200: <OutputSerializer>},
    )
    @action(detail=True, methods=["POST"])   # detail=True → /api/resource/<id>/action/
    def publish(self, request, pk=None):
        """Publish this item."""
        obj = self.get_object()
        obj.publish()
        serializer = <ModelName>Serializer(obj)
        return Response(serializer.data, status=status.HTTP_200_OK)

    @swagger_auto_schema(
        method="GET",
        responses={200: <OutputSerializer>(many=True)},
    )
    @action(detail=False, methods=["GET"])   # detail=False → /api/resource/action/
    def featured(self, request):
        """List featured items."""
        qs = self.get_queryset().filter(is_featured=True)
        serializer = <ModelName>Serializer(qs, many=True, context={"request": request})
        return Response(serializer.data, status=status.HTTP_200_OK)
```

**Action URL patterns (auto-generated by router):**
- `detail=True` + `methods=["POST"]` → `POST /api/<resource>/<id>/publish/`
- `detail=False` + `methods=["GET"]` → `GET /api/<resource>/featured/`
- The URL name is `api:<basename>-<action_name>` (e.g., `api:posts-publish`)

## Pattern B — New ViewSet for a Resource

Use when creating CRUD endpoints for a new model.

**In `apps/<appname>/views.py`:**

```python
from drf_yasg.utils import swagger_auto_schema
from rest_framework.mixins import (
    CreateModelMixin,
    DestroyModelMixin,
    ListModelMixin,
    RetrieveModelMixin,
    UpdateModelMixin,
)
from rest_framework.permissions import IsAuthenticated
from rest_framework.viewsets import GenericViewSet

from .<models> import <ModelName>
from .serializers import <ModelName>Serializer, <ModelName>WriteSerializer


class <ModelName>View(
    CreateModelMixin,     # POST   /api/<resource>/
    RetrieveModelMixin,   # GET    /api/<resource>/<id>/
    UpdateModelMixin,     # PATCH  /api/<resource>/<id>/
    DestroyModelMixin,    # DELETE /api/<resource>/<id>/
    ListModelMixin,       # GET    /api/<resource>/
    GenericViewSet,
):
    queryset = <ModelName>.objects.filter(is_active=True)
    serializer_class = <ModelName>Serializer
    permission_classes = [IsAuthenticated]
    filterset_fields = ["is_active", "status"]
    search_fields = ["title", "body"]
    ordering_fields = ["created_at", "updated_at"]

    def get_serializer_class(self):
        if self.action in ("create", "update", "partial_update"):
            return <ModelName>WriteSerializer
        return <ModelName>Serializer

    def get_queryset(self):
        # Scope to the current user's data:
        return self.queryset.filter(owner=self.request.user)

    def perform_create(self, serializer):
        # Inject owner automatically from authenticated user:
        serializer.save(owner=self.request.user)
```

**Only include the mixins you actually need:**
- `ListModelMixin` → `GET /api/<resource>/`
- `CreateModelMixin` → `POST /api/<resource>/`
- `RetrieveModelMixin` → `GET /api/<resource>/<id>/`
- `UpdateModelMixin` → `PATCH/PUT /api/<resource>/<id>/`
- `DestroyModelMixin` → `DELETE /api/<resource>/<id>/`

**In `apps/<appname>/urls.py`:**

```python
from django.urls import include, path
from rest_framework.routers import DefaultRouter

from .views import <ModelName>View

router = DefaultRouter()
router.register("<resource>", <ModelName>View, basename="<resource>")

urlpatterns = [
    path("", include(router.urls)),
]
```

**In `config/api_urls.py`:**

```python
urlpatterns = [
    path("", include("apps.users.urls")),
    path("", include("apps.<appname>.urls")),
]
```

## Pattern C — Standalone CreateAPIView (for actions without a model, or auth-style endpoints)

Use for endpoints that perform a single action (e.g., sending an email, verifying something, triggering a process).

```python
from drf_yasg import openapi
from drf_yasg.utils import swagger_auto_schema
from rest_framework import status
from rest_framework.generics import CreateAPIView
from rest_framework.permissions import IsAuthenticated
from rest_framework.response import Response

from .serializers import <ActionSerializer>


# Define the response schema inline if no serializer exists
_response_schema = openapi.Schema(
    type=openapi.TYPE_OBJECT,
    properties={"message": openapi.Schema(type=openapi.TYPE_STRING)},
)


class <ActionName>View(CreateAPIView):
    serializer_class = <ActionSerializer>
    permission_classes = [IsAuthenticated]   # or AllowAny

    @swagger_auto_schema(
        operation_description="Description of what this endpoint does",
        responses={200: _response_schema},
    )
    def create(self, request, *args, **kwargs):
        serializer = self.get_serializer(data=request.data)
        serializer.is_valid(raise_exception=True)
        result = serializer.save()
        return Response(result, status=status.HTTP_200_OK)
```

**In `apps/<appname>/urls.py`:**

```python
urlpatterns = [
    path("auth/some-action/", <ActionName>View.as_view(), name="some-action"),
    path("", include(router.urls)),
]
```

## Swagger Documentation Rules

Always document endpoints. Use one of these patterns:

```python
# 1. Simple response with a serializer
@swagger_auto_schema(method="GET", responses={200: MySerializer})

# 2. Response with a list
@swagger_auto_schema(method="GET", responses={200: MySerializer(many=True)})

# 3. Custom inline schema (no serializer)
@swagger_auto_schema(
    method="POST",
    responses={
        200: openapi.Schema(
            type=openapi.TYPE_OBJECT,
            properties={"message": openapi.Schema(type=openapi.TYPE_STRING)},
        )
    },
)

# 4. Document request body + response
@swagger_auto_schema(
    method="POST",
    request_body=InputSerializer,
    responses={201: OutputSerializer},
)

# 5. Describe operation
@swagger_auto_schema(
    operation_description="Publishes the item and sends a notification.",
    responses={200: MySerializer},
)
```

## Permission Classes Reference

```python
from rest_framework.permissions import AllowAny, IsAuthenticated
from apps.common.permissions import IsOwner

# Public endpoints (signup, login, password reset)
permission_classes = [AllowAny]

# Authenticated users only
permission_classes = [IsAuthenticated]

# Object must belong to the requesting user
permission_classes = [IsAuthenticated, IsOwner]
```

## Filtering, Searching, Ordering

```python
class MyView(ListModelMixin, GenericViewSet):
    filterset_fields = ["status", "is_active"]   # ?status=draft&is_active=true
    search_fields = ["title", "body"]             # ?search=hello
    ordering_fields = ["created_at", "price"]    # ?ordering=-created_at
```

## Returning Custom Responses

```python
# Single object
return Response(serializer.data, status=status.HTTP_200_OK)

# Created object
return Response(serializer.data, status=status.HTTP_201_CREATED)

# Message only
return Response({"message": "Done."}, status=status.HTTP_200_OK)

# No content (delete)
return Response(status=status.HTTP_204_NO_CONTENT)

# Raise validation error (returns 400)
from rest_framework.exceptions import ValidationError
raise ValidationError({"field": "Error message."})
```

## URL Naming Reference

All URL names use the `api:` namespace. Use `reverse("api:<name>")` in tests.

| Pattern | Name | Usage |
|---------|------|-------|
| Router ViewSet | `api:<basename>-list` | `reverse("api:posts-list")` |
| Router ViewSet detail | `api:<basename>-detail` | `reverse("api:posts-detail", args=(pk,))` |
| Router custom action | `api:<basename>-<action>` | `reverse("api:posts-publish", args=(pk,))` |
| Standalone path | `api:<name>` | `reverse("api:signup")` |

## Checklist

- [ ] View has explicit `permission_classes`
- [ ] ViewSet uses only required mixins
- [ ] `get_serializer_class()` used when read/write serializers differ
- [ ] `get_queryset()` scopes data correctly (especially by user)
- [ ] `perform_create()` injects request user if needed
- [ ] Every custom `@action` has `@swagger_auto_schema`
- [ ] Standalone views have `@swagger_auto_schema` on `create()`
- [ ] URLs registered in app `urls.py`
- [ ] App URLs included in `config/api_urls.py`
- [ ] URL names follow `api:<basename>-<action>` pattern
- [ ] Tests cover the new endpoint (see `write-tests.md`)
